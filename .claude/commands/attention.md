description: Everything that wants a decision this week, worst first. Limitation dates, missed deadlines, overdue undertakings, blown estimates, stale WIP, missing CDD, quiet matters.
---

1. Run `npm run matters -- attention`.
2. The list is already ordered by how much each item can cost. Read it in that order and do not reorder it by ease:
   - **A limitation date passed or closing in** outranks everything on this list and most things off it.
   - **A missed key date or an overdue undertaking** is a professional obligation already breached; the move is action plus honesty, today.
   - **Missing CDD on an open matter** is a legal problem, not an admin one (AML/CFT Act 2009). It gets fixed before more work goes on the clock.
   - **Client care file gaps** are what a standards committee reads first when a complaint lands.
   - **Work past the estimate** is a complaint that has not been posted yet. Ring first, bill second (r 3.5).
   - **Overdue invoices, stale WIP, drafts never sent** are the firm's own money, asleep.
   - **Quiet matters** are the clients quietly deciding to complain, or to leave.
3. For each item, say the one action: the command to run, the call to make, or the record to fix. Name the lawyer who owns it.
4. Anything that needs a letter or an email is drafted, never sent: `npm run docs`, or write to `drafts/`.

If the operator asks "what should I do today", pick the top three and say why those three.
