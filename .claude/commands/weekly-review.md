---
description: The Monday review, written from three commands. The dates, the register, the money and the file, then the five things that matter this week.
---

Run these three, in this order, and write the review from what they return. Do not write anything they do not support.

```
npm run matters -- attention
npm run matters -- key-dates
npm run matters -- lockup
```

Then write it in this shape, no more than a page:

1. **The week in one line.** Open matters, total lock-up (WIP plus debtors), key dates inside 14 days, open undertakings, and whether anything on the file is missing.
2. **Dates that bite this week.** Limitation dates first and always, then settlements, hearings, filings, renewal notices. Each with its lawyer and the single next action.
3. **The register.** Any undertaking overdue or due this week, in its exact wording, with who gave it.
4. **The money.** Lock-up by client, the invoices past 30 days, WIP going stale, drafts never sent. One line each with the move.
5. **The file.** Client care records missing on open matters, clients with no CDD, and any practising certificate about to lapse. These are the lines a standards committee or the DIA reads.
6. **Quiet matters.** Open files with money on the clock and no activity in 30 days. Each one is a client forming an opinion.
7. **The five things to do this week.** Pick them from the attention list, weighted by what breaches first and what it costs, and say why each made the list.
8. **One thing to decide.** The single item that needs a person, not a process.

Add `npm run view -- week` and `npm run view -- money` if the operator wants pages to take to a partners' meeting. They render the same numbers in the firm's brand, and they print.

Numbers come from the commands. If a number is not in the output, it does not go in the review.
